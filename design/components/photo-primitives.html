Components

Photo primitives

Photographs are the content of this product, so these components stay out of the way: a rounded frame, a scrim only where text sits on top, and a selection treatment that survives being drawn over an arbitrary image.

The "photographs" below are CSS gradients. The design project blocks external hosts, so stand-ins are generated rather than fetched. They make composition legible without pretending to be art direction.

Aspect ratios

4:3 — grid default
1:1 — filmstrip
3:4 — portrait

Fixed aspect ratios on the container, with the image covering it. The alternative — letting each photo set its own height — produces a ragged grid and a page that reflows as images load.

Unplaced photos are normal, not exceptional. Screenshots, scans, and anything shot with location services off carry no GPS EXIF at all — a large fraction of a real library. They get a dashed warning border and an explicit badge so they are visibly accounted for rather than silently dropped from the map.

Selection is an outline with an offset rather than a color overlay, because it has to remain visible against a photograph of any color — including a photograph that happens to be teal.

Filmstrip

Caption and scrim

A scrim appears only where text overlays the image. A gradient from 78% opacity at the bottom to transparent at 62% height keeps the caption readable over a bright photograph without dimming the whole frame.
