Components

Upload

A dropzone and a per-file result list. Uploads are batches, and batches partially fail — so the design's job is making a mixed outcome legible rather than pretending every batch succeeds or fails as a unit.

Dropzone states

Idle

Drop photos here

or choose files · JPEG, PNG, WebP · up to 25 MB each

Drag over

Release to upload 12 photos

They will be added to your library

Rejecting

Only image files are supported

3 of these 5 files are not images

The rejecting state fires on dragover, before the drop. Telling someone their file is unsupported while they are still holding it is meaningfully better than accepting the drop and then failing.

Client-side type checking is a courtesy, never a control. The browser reports what the file claims to be. The server decides what it actually is by inspecting magic bytes, and it must reject a .jpg whose contents are HTML regardless of what this dropzone allowed through.

The summary counts every outcome, including the failures. A summary that reports only successes lets someone walk away believing a batch completed when two files never made it.
