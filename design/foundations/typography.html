Foundations

Typography

A system font stack and a nine-step scale. No webfonts: the design project blocks external hosts outright, and a photo-heavy product has better uses for that request budget than a typeface.

Why system fonts, beyond the CSP. No render-blocking request, no flash of unstyled or invisible text, no layout shift when a face swaps in, and native rendering on every platform. The cost is that the product does not have a distinctive typographic voice — a real tradeoff, and one worth revisiting if a brand direction emerges.

Scale

A 1.25 major-third ratio, rounded to whole pixels at a 16px root. Each step lists the role it serves — the roles are the point, not the numbers.

Form inputs never go below 16px on mobile. iOS Safari zooms the viewport when a focused input has a font size under 16px, which throws the layout off and is jarring mid-form. Use --pv-text-base for the input itself and --pv-text-xs for its label.

Line height and measure

Four line-height steps: tight 1.15 for display, snug 1.3 for headings, normal 1.5 for interface text, relaxed 1.65 for sustained reading.

Measure capped at 68ch

Voyage descriptions are the only long-form text in the product, and they are capped at roughly 68 characters per line. Beyond about 75 characters the eye loses its place on the return sweep; below about 45 it breaks the rhythm of reading. Everything else in the interface is short enough that measure does not come up.
