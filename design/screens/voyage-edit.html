Voyage create & edit

Metadata on the left, publishing decisions on the right. Create and edit are the same screen — the only difference is whether the voyage has ever been published.

Publishing is the irreversible-feeling moment, so it is deliberately not a quiet toggle at the bottom of a form. Every voyage is public once published, and the granularity control sits directly above the publish button because that is the decision the user needs to have made first.

Annotations

1Granularity sits directly above Publish on both breakpoints. Adjacency is the argument: the last thing seen before making a voyage public is the precision it will be published at.
2Unplaced photos are visible in the editor grid with a dashed outline and a count, so the discrepancy between "48 photos" and the number of pins on the map has an explanation on the same screen.
3Delete says where the photos go. "Its photos return to your library" removes the fear that deleting a voyage destroys the pictures — which is the reason people leave dead voyages lying around.
4The draft badge is in the header on both breakpoints, persistent rather than inferred from a toggle position.
